# Sovrack — Scripts Utilitaires

Ce répertoire regroupe les scripts d'outillage local et de personnalisation de marque.

## Contenu

- `apply-brand.ps1` : Script d'automatisation pour adapter les constantes de marque (nom, slug, domaine).
- `generate_icons.py` : Génération des icônes et favicons SVG / PNG pour le frontend.
- `generate_sovrack_brand.py` : Génération des assets visuels officiels Sovrack.
- `generate_transparent_icons.py` : Extraction et optimisation des logos en fond transparent.

> **Note :** Les scripts opérationnels de production (déploiement, sauvegardes PostgreSQL, certificats SSL Certbot, rollback) sont situés dans [`infra/scripts/`](../infra/scripts/).
